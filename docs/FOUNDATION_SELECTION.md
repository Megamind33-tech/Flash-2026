## Decision

**Randomation Vehicle Physics (RVP) + GRIDLINE race/league layer.**

- RVP is the only candidate that is MIT-licensed *with* redistributable art, has believable (not arcade) vehicle dynamics,
  damage, ground surfaces, automatic/manual transmission and mobile prefabs.
- No candidate had a race layer we could legally reuse wholesale, so GRIDLINE adds its own: grid, countdown, lap/sector
  timing, positions, penalties, recovery, results, career economy and a circuit-racing AI (RVP's `FollowAI` is a waypoint
  follower with no braking-zone planning). RVP code is used through its public API; vendored files are only touched for
  Unity 6 API renames.
- Verified integration result: the vendored RVP scripts compile against Unity **6000.3.27f1** after two mechanical
  renames (`PhysicMaterial`→`PhysicsMaterial`, `ScreenOrientation.Landscape`→`LandscapeLeft`). Runtime behaviour on
  Unity 6 is **not yet verified** (needs a licensed editor run — see STATUS.md).
