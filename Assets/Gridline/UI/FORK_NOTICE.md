GRIDLINE's UI is a fork of the screen architecture of Unity Technologies' UI Toolkit runtime demo
"Unity Royale" — https://github.com/Unity-Technologies/UIToolkitUnityRoyaleRuntimeDemo (checked 2025-10-23 HEAD).

Forked: the UI Toolkit runtime structure — UIDocument + PanelSettings per scene, UXML screens with USS styling,
title/options/game/end screen split, and screen switching by toggling `display` on named screen roots
(Royale's TitleScreenManager pattern, now `ScreenNavigator`). Not forked: Royale's fantasy card art and cartoon fonts.
